# 《温泉小镇复兴》雾见町地图与分区开放规划
## Town Map & Region Unlock Plan
### V0.1

> 本文档是雾见町地图的**唯一权威版本**。产品结构设计稿 §13、World Bible §10 的地图描述均以本文档为准。
> 原则：**整张地图一次定好，3D 资产按区域分批制作、按章节分批开放。**

---

# 1. 设计原则

1. **整图先定**：所有区域的位置、道路、河流、地形高差在第一版就确定，后续扩区不改动已有区域的位置。
2. **未开放区域用"雾"遮住**：雾见町名字来自晨雾，未开放区域被一层薄雾覆盖，只露出轮廓剪影。开放新区域 = 雾散开。这同时是 World Bible 的视觉母题"从看不清未来，到重新看见这座镇"。
3. **分批建模**：未开放区域在 3D 里只需要低模剪影（Blockout），开放前一个版本再做成正式模型。
4. **镜头**：45° 俯视，可拖动、可缩放，不旋转（产品结构稿 §12）。所以每栋建筑只需要做好**正面和两个侧面**，背面可以极简。

# 2. 总体布局

```text
                         【北：群山】
                            山路
                              │
                         ⑨ 温泉源头（S2+）
                              │ 温泉管线
 铁路(停运)                    │
 ═══╗   ┌──────── ② 商店街前段 ──────── ④ 商店街后段 ────┐
    ║   │  千鹤堂  春江杂货店  空铺      旧食堂  茶屋  土产店 │
 ① 旧车站区                                              ③ 公共浴场
   站牌 / 候车室                                           │
   项目办公室小屋                                     ⑥ 老旅馆区「月见庄」
    │                                                       │（后门旧路）
 ~~~~~~~~~~~~~~~~~~~~~~ ⑤ 河岸（石桥 / 步道 / 樱花 / 河岸仓库）~~~~~~~~~~~
                              │ 石桥
                     ⑧ 夏祭广场（河岸南侧）
                              │ 参道石阶
                         ⑦ 神社（高处）
                         【南：小山】
```

- 河流自东北向西南穿过小镇，把镇分成北岸（生活区）和南岸（神社与祭场）。
- 商店街是一条东西向主街：西头连旧车站，东头到公共浴场。
- 夏祭广场位于**河岸南侧、神社参道石阶下方**，因此它既是"河岸"的一部分，也是"神社参道"的终点（解决旧文档中夏祭广场位置不一致的问题）。

# 6. 时间与天气状态

S1 需要的全局状态（全部区域通用）：

- 白天 / 夜晚（夜景亮灯是核心反馈，Vertical Slice 必须有）
- 晨雾（开场与未开放区域）
- 雨天（Ch6 梅雨）
- 台风（Ch9，可用雨天 + 风效 + 局部损坏部件表现）
- 夏祭夜（Ch10，灯笼、摊位、人流、烟花）
